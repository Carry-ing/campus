# 大学校园体验页（campus）

> 纯静态站点，一键发布到 GitHub Pages：`git push` 之后由 `.github/workflows/pages.yml`
> 自动把 `index.html` + `css/` + `js/` 发布出去（`server.js`、`__probe.html`、`scripts/`、`.shots/`
> 只在本地用，不会上线）。站点跑在 `/仓库名/` 子路径下，页面里所有资源都是相对路径，不需要改配置。

一个零依赖的纯前端体验页，四个界面串成一条线：

| 界面 | 内容 | 返回键 |
| --- | --- | --- |
| 1 欢迎页 | 艺术字「欢迎进入大学校园」+ emoji 贴图 + 页面正中的「进入」按钮（年份 2026） | —（入口页，没有上一个界面） |
| 2 三句话 | `进入了大学` → `就代表了无限的机会和试错` → `有很多的活动在等待着你` 逐句弹出，讲完自动进入下一页 | ← 返回欢迎页 |
| 3 活动气泡页 | 顶部固定「看看都有什么活动可以参加」，26 个气泡会自己缓慢飘动、相撞时会轻微挤压；**正中央另有一颗白色气泡「发布你的活动」** | ← 返回三句话 |
| 4 活动详情页 | 点气泡后进入的新页面：分类配色、环绕贴纸、关键信息卡、注意事项、风险提示，底部有一行红色小字「内容并不完全，细节请等待官方通知」 | ← 返回（顶部 + 底部各一个） |
| 5 发布你的活动 | 填表发布自己的活动（名称/图标/分类/简介/时间/地点/参加方式/对象/小贴士），发布后回到气泡墙，中央会**吹出一颗新气泡** | ← 返回气泡墙 |

没有任何构建步骤、没有第三方依赖、不联网也能跑（艺术字体联网时自动加载，离线自动回退系统字体）。

## 快速开始

```bash
cd campus
node server.js          # 默认 5180 端口，监听 0.0.0.0
```

浏览器打开 <http://localhost:5180>。

- 换端口：`$env:PORT=8081; node server.js`（Windows） / `PORT=8081 node server.js`（macOS、Linux）
- 不想用这个 server 也行：`campus/` 是纯静态目录，任何静态服务器都能托管

## 网址与路由

界面之间用 `#/xxx` 路由串起来，所以**浏览器的返回键、手机上的返回手势都能用**，
返回后再进入时，气泡页的拖动位置和「已探索」进度都会保留：

| 路由 | 界面 |
| --- | --- |
| `#/welcome` | 欢迎页（默认） |
| `#/intro` | 三句话 |
| `#/activities` | 活动气泡页 |
| `#/activity/24` | 第 24 个活动的详情页（自己发布的从 1001 开始编号） |
| `#/publish` | 发布你的活动 |

调试时可以直接改地址栏跳转，也可以在控制台用 `campusGo('activity/7')`。

## 发布自己的活动（中央那颗白气泡）

气泡墙正中央有一颗**稍微大一点的白色气泡「发布你的活动」**（直径是格子边长的 0.74 倍，
普通气泡是 0.50~0.64 倍）。点它进入发布页，填完点「吹出这颗气泡 ✨」就会：

1. 回到气泡墙
2. 中央冒出一圈气环 + 一堆小泡泡（吹气特效）
3. 新气泡**由小变大**长出来（0.55 秒，中段还会微微鼓起），长好之后自己开始飘，加入物理系统
4. 中央那颗白气泡被"吹"得鼓一下，右上角「已探索 n / 总数」的总数 +1

新气泡的格式与其它气泡完全一致：同样的圆形外观、分类配色（跟着你选的分类走）、
同样的字号自适应（长名字自动缩到圆内不被裁）、点进去是同样结构的详情页
（分类、一句话简介、信息卡、注意事项、底部红字）。

细节说明：

- **必填只有「活动名称」**，其余留空也能发布；留空的项不会出现在详情页里
- 图标从 18 个里挑一个；分类从 13 个里挑一个（默认「学生发起」）
- 中央那颗白气泡是**静态障碍物**（逆质量为 0）：自己不动，但别的气泡撞上来会被弹开，
  而且一开始的网格布局会自动跳过它周围的槽位，不会一进来就叠在一起
- 发布的内容存在**本机浏览器的 localStorage**（键名 `campus.myActivities.v1`），
  刷新、关掉再打开都还在；换设备或清缓存就没了（页面上也写了这句提示）
- 自己发布的活动在详情页底部多一个「删除这个活动」按钮，点两次确认即可删除（不弹系统对话框）
- 不填名字直接点发布会就地提示「先给活动起个名字吧」，不会离开当前页面

## 气泡页是怎么做的（想调参看这里）

### 尺寸与文字

- 气泡直径 = 格子边长 × 0.50~0.56（大屏）、× 0.58~0.64（小屏，屏幕小所以相对大一点）
- **名字字号是按标题长度自动算出来的**：先按字符数估一个初值（中文算 1 个字宽、字母数字算 0.55），
  再实测图标与名称四个角是否都落在圆内，超出就按 6% 步长缩字号，直到完全落在圆内为止。
  所以像「“蓝桥杯”程序设计校内训练营」这种长标题会自动排成两行小字，一个字都不会被裁掉。
- 名称框宽度固定为气泡直径的 84%，最多三行，行高 1.16。

### 自走 + 碰撞

气泡的位移与碰撞在 `js/main.js` 的 `stepPhysics()` 里，参数都在文件顶部：

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| `SPEED_MIN` / `SPEED_MAX` | 9 / 34 px/s | 速度区间：一直在慢慢动，但不会飘到晃眼 |
| `WALL_DAMP` | 0.94 | 撞到场地边界的能量损失 |
| `RESTITUTION` | 0.55 | 碰撞弹性，越小越"闷" |
| `SQUASH_MAX` | 0.10 | 最大挤压 10%，克制不夸张 |

- 每帧按 dt 积分位移、撞墙反弹，然后两两检查圆形碰撞：按"质量"（面积）分摊把彼此挤开，
  再沿法线交换动量（带弹性），最后把速度限幅在 `SPEED_MIN`~`SPEED_MAX` 之间
- **挤压形变是按撞击速度算的**，不是按几何重叠量：慢速运动里每帧穿透只有零点几像素，
  用重叠量算出来只有 0.5%，肉眼完全看不见；改成按撞击速度后能到 10% 上限，
  碰撞时沿法线压扁、垂直方向微微鼓起，之后约 0.3 秒自己回弹
- 结构上分了两层：`.bubble-holder` 只吃 JS 写入的位移/挤压 transform，
  `.bubble` 负责外观与入场动画。这样 JS 的 transform 不会和 CSS 动画抢同一个属性
- 关掉动画：`prefers-reduced-motion` 时气泡不动；自检页用 `campusPhysics.pause()` + 手动 tick
- 调试入口：控制台里 `campusPhysics.state()` 看所有气泡的位置/速度/挤压量，
  `campusPhysics.tick(0.05)` 手动推进一帧，`campusPhysics.collisions()` 看累计碰撞次数

### 拖动不会选中文字

- `.field-wrap` 与 `.bubble` 上设了 `user-select:none`（并带 `-webkit-` 前缀与 `-webkit-touch-callout:none`）
- 拖动开始时清掉已有选区，并额外拦截 `selectstart` / `dragstart` 兜底
- 详情页没有禁选，活动信息想复制照样可以复制



服务默认监听 `0.0.0.0`，启动日志里会直接打印可用的局域网地址，例如：

```
校园体验页已启动 → http://localhost:5180
同一个局域网（同一个 WiFi）里可以用这些地址访问：
   http://172.34.66.37:5180
```

把 `http://<你的IP>:5180` 发给同一个 WiFi 下的手机 / 电脑即可。

**别人打不开时先看防火墙**：Windows 第一次监听端口会弹「是否允许访问」，要勾选**专用网络**；
如果当时点了取消，可以手动放行（需要管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "campus 5180" -Direction Inbound -LocalPort 5180 -Protocol TCP -Action Allow
```

## 不同局域网访问（4G/5G、别人家的宽带）

「同一个 WiFi 能用」不等于「不同网络也能用」——后者需要一个**公网可达的地址**。最快的方式是临时隧道：

```powershell
# 本机 bin 目录里已经有 cloudflared.exe（ShareWall 项目下载过的那个）
& "..\bin\cloudflared.exe" tunnel --url http://127.0.0.1:5180 --no-autoupdate
```

命令会打印一个形如 `https://xxxx-xxxx.trycloudflare.com` 的公网地址，发给任何人都能打开。
当前这条隧道已经跑起来了，地址写在 `campus/public-url.txt`（重启隧道会变化）。

- 免费、不用注册；但**本机必须一直开着**，关掉窗口或重启就会换一个新地址
- 这条免费隧道偶尔会静默断线（进程还活着、域名已失效，访客看到 `Error 1033 / HTTP 530`）；
  断了重新执行上面的命令、把新地址发出去即可
- 想让地址**长期固定**：把 `campus/` 和 `server.js` 部署到一台长期开机的机器，
  或用平台给的域名访问；`campus/` 是纯静态的，也可以直接丢到对象存储 / CDN 上
- 不想暴露到公网：所有设备装 Tailscale / ZeroTier 组一个虚拟局域网，用 `http://<虚拟IP>:5180` 互相访问

## 自检（可选）

两个检查，作用不同，建议都跑：

### 1. `__probe.html` —— 页面内自检（116 项断言）

在 iframe 里加载真实页面，把完整流程走一遍并打印断言结果。

```powershell
powershell -File scripts\real-click-check.ps1 -Probe
```

- 已实测：**116 项断言全部通过**（ALL PASS）
- 为什么不直接用 `--dump-dom` 抓：无头浏览器在外部字体等请求挂住时会暂停虚拟时钟，
  页面里的 `setTimeout` 就不触发了，自检页会卡住；`-Probe` 用真实时间跑，稳得多
- 也可以人工看：浏览器打开 <http://127.0.0.1:5180/__probe.html>，页面下方会显示 `SUMMARY = ALL PASS`

### 2. `scripts/real-click-check.ps1` —— 真实鼠标输入（34 项断言）

```powershell
node server.js                            # 先启动服务
powershell -File scripts\real-click-check.ps1
```

走 Chrome DevTools Protocol 的 `Input.dispatchMouseEvent` / `Input.insertText` 派发**真实输入**，
行为和手点手打一致。

为什么必须有它：JS 里 `dispatchEvent` 造出来的合成事件会绕过真实指针处理流程，
所以 `__probe.html` 全绿也**测不出「点气泡没反应」**这类问题（这次就踩了这个坑）。
已实测 34 项全部通过，覆盖：真实点击气泡跳详情页、真实拖动会平移且不误触、
四个界面的返回键、浏览器返回键、气泡在真实时间里确实在飘（3 秒 26/27 移动、最快 34px/s）、
**鼠标拖过气泡不会选中任何文字**、**真实点击中央发布气泡 → 真实键盘打字 → 真实点击发布 → 新气泡出现并吹完**。

## 更新记录

- **新增「发布你的活动」（本次）**：气泡墙正中央加了一颗稍大的白色气泡，
  点进去是发布表单，发布后回到气泡墙并**从中央吹出一颗新气泡**（气环 + 泡泡粒子 + 由小变大），
  新气泡的格式、配色、字号自适应、详情页与原有的 26 个完全一致，存在本机 localStorage 里，
  可以再删掉。中央那颗白气泡作为静态障碍物参与碰撞，别的气泡会绕着它弹开。
  自检里为此加了 30 项断言，真实输入脚本加了 6 项（含真实键盘打字）。
- **气泡页调整**：
  1. 气泡整体变小（大屏直径约为原来的 0.85 倍），并且**名字字号改成按标题长度自动适配**——
     长标题自动排两行小字，实测 26 个气泡的图标和文字四角全部落在圆内，一个字都不会被裁掉；
  2. 气泡改成**自己在场地里缓慢飘动**（9~34 px/s），带惯性和边界反弹；
  3. 气泡之间加了**碰撞**：按面积分摊挤开 + 沿法线交换动量，接触时**沿法线轻微挤压形变**
     （上限 10%，约 0.3 秒回弹）。这里有个坑：一开始用几何重叠量算形变，
     但慢速运动每帧只穿透零点几像素，算出来只有 0.5%，肉眼看不见，改成按撞击速度算才明显；
  4. **拖动时不会再选中活动名称**：`user-select:none` + 拖动时清选区 + 拦截 `selectstart`。
- **修复「点气泡没反应，跳不到活动介绍页」**（重要）：
  拖拽代码里调用了 `setPointerCapture`。指针一旦被捕获，浏览器会把手势结束时的 `click`
  派发到**捕获元素**（也就是那层拖拽容器）上，气泡自己的 `click` 永远不会触发。
  现在改成在 `window` 上监听移动/抬起，滑动效果不变，但子元素照常收到 click。
  这个 bug 之所以没被 `__probe.html` 发现，是因为合成事件绕过了真实指针流程——
  所以新增了 `scripts/real-click-check.ps1`，用真实鼠标输入来测，并给自检页加了
  「拖拽代码不得调用 setPointerCapture」的哨兵断言。
- **修复「退场的界面会挡住新界面的点击」**：`visibility` 过渡有 0.7s，退场界面在这段时间里
  仍然可见且可点，叠在新界面之上。已给非当前界面加 `pointer-events:none`
  （表现为点「进入」按钮、快速连点时会失灵）。
- 欢迎页年份改为 **2026**。
- 每个活动介绍页底部新增一行红色小字：**内容并不完全，细节请等待官方通知**。
- **修复「三句话只有第一句显示」**：第 2、3 句的样式里用了 `background` 简写来换渐变，
  而简写会把上一条规则里的 `background-clip:text` 重置回 `border-box`，
  结果文字透明、渐变铺满整块。改用 `background-image`（长属性）后恢复正常，
  并在自检页里加了两条回归断言，专门盯着 `background-clip` 是不是 `text`。
- **26 个气泡换成你提供的活动资料**，点气泡不再是弹窗，而是进入独立的详情页。
- **每个界面都加了返回键**（欢迎页是入口，没有上一个界面，所以没放），
  并接入 `#/xxx` 路由，浏览器返回键与手机返回手势同样有效。
- 返回气泡页时会保留拖动位置与「已探索」进度；从气泡页返回三句话时立即显示三句，
  不会又把你自动推回下一页。

## 小细节

- 拖动和点击是分开的：手指滑动超过 9px 就只在滑屏，不会误触跳转
- 气泡带惯性和边界回弹，甩一下会滑一段距离（滑行距离约为拖动距离的 2 倍）
- 看过的气泡会打勾，「已探索 n / 26」实时计数，26 个全看完会有一句提示
- 详情页的配色跟着活动分类走，主图标与环绕贴纸都带浮动动画
- 气泡位置由网格 + 随机抖动生成，每次刷新布局都不同，但保证互不重叠
- 移动端已处理安全区（刘海屏）、禁止双击缩放、详情页可上下滚动
